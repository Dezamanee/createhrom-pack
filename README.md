# createhrom — сборка Minecraft

Готовая сборка на **Minecraft 1.21.1 + NeoForge**: индустриальный Create с авиацией и подводными лодками, фермерство, мебель, кинематографичные камеры и графика.

## Что внутри

| Файл | Содержимое | Размер |
| --- | --- | --- |
| `mods.rar` | 91 мод + конфиги сборки | ~332 МБ |
| `resourcepacks.rar` | 5 ресурспаков | ~13 МБ |

Ключевые моды: Create 6.0.10, Create Aeronautics, Create: Diesel Generators, Create Nuclear, Create Big Cannons, Create Deco, TFMG, Create New Age, Create Submarine, Farmer's Delight с аддонами, серия Let's Do (Furniture, Meadow, Vinery, Farm & Charm), Waystones, Sophisticated Backpacks, JEI, Iris + Sodium, звуки и кинематографичные камеры.

Полные списки: [`MODS.md`](MODS.md) и [`RESOURCEPACKS.md`](RESOURCEPACKS.md).

## Установка

1. Установите **Minecraft 1.21.1** и **NeoForge** для неё (или используйте свой лончер с поддержкой NeoForge).
2. Распакуйте `mods.rar` в `.minecraft/versions/createhrom/mods/` — так, чтобы `.jar`-файлы лежали прямо в папке `mods`, без вложенных каталогов.
3. Распакуйте `resourcepacks.rar` в `.minecraft/versions/createhrom/resourcepacks/`.
4. Запустите игру и включите ресурспаки в «Настройки → Наборы ресурсов».

Путь на Windows: `%APPDATA%\.minecraft\versions\createhrom\`

> Если распаковать архивы в общую папку `.minecraft/mods`, сборка будет конфликтовать с другими версиями — папка `versions/createhrom` отдельная.
